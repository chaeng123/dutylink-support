## 게시 방식

GitHub Pages가 `main` 브랜치의 루트 디렉터리를 게시합니다. 정적 HTML만 사용하며 별도 빌드, 외부 글꼴, 분석 스크립트가 없습니다. 메일 링크는 사용자의 메일 앱을 엽니다.

## 문서 상태

개인정보 처리방침은 운영 정보 확인 중인 **초안**입니다. 실제 저장 지역, 외부 서비스의 처리 정보, 문의·로그 보관기간과 신고 대응 절차를 확인한 뒤 최종 문서로 갱신해야 합니다. 사이트 게시 완료와 App Store 출시 준비 완료는 별개입니다.

원본은 앱 프로젝트의 `docs/privacy/`에 있으며 `NurseShiftAI/Resources/`의 번들 사본과 함께 갱신합니다. `.p8`, 서비스 계정 키, 사용자 문의 자료를 이 저장소에 올리지 마세요.
